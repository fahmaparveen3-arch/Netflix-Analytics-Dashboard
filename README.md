# Netflix Movies & TV Shows Analytics Dashboard using Python

A Big Data analytics project using Python and Google Colab to analyze Netflix movies and TV shows data through visual dashboards.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly
- WordCloud
- Google Colab

## Features

✅ Movies vs TV Shows Analysis  
✅ Netflix Content Growth Analysis  
✅ Country-wise Content Analysis  
✅ Ratings Distribution  
✅ Genre Analysis  
✅ Interactive Plotly Dashboard  
✅ Word Cloud Visualization  
✅ Top Directors Analysis

## Dataset

This project uses:

`netflix_titles.csv`

Dataset source:
Netflix Shows Dataset from Kaggle.

## Project Outputs

- Pie charts
- Bar charts
- Line graphs
- Interactive dashboards
- Word cloud visualization

## How to Run

1. Open Google Colab  
2. Upload `netflix_titles.csv`  
3. Run all cells  
4. View analytics dashboard
